# 伦理与数据合规声明底稿

> 本文是项目维护模板，不替代学校、赛事方或法律顾问要求的正式文件。

我们承诺：

1. LearnFlow 演示数据为合成 seeded data，不含未经授权的真实学生个人信息、成绩、账号、联系方式或其他敏感数据。
2. 如开展目标用户测试，只收集完成任务所需的最小信息；公开材料使用匿名编号，并在取得知情同意后保存反馈。
3. 不使用系统伪造实验结果、用户反馈、引用、标准编号或学术数据。领域知识来源保留书名/标准号、页码或 URL 与授权状态。
4. AI 生成的讲义、解释、路线或反馈在产品和提交材料中作明显标识；生成内容不自动视为正确或视为学习者掌握证据。
5. 纠错策略、评分和五核状态更新受确定性规则与 EvidenceEvent 约束，可追溯、可纠正；外部模型和星辰工作流不能直接写学习者状态。
6. API key、Cookie、`.env`、日常数据库和可识别用户的数据不进入公开仓库或提交压缩包。
7. 代码执行、外部来源抓取和模型输出存在安全边界；演示环境使用隔离数据库，并应在受控设备上运行。
